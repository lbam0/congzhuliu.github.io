# PEACH Lab

A bilingual, responsive homepage for PEACH Lab.

## Customize

- Edit `index.html` to update the lab introduction, research themes, member biographies, contact details, and translations.
- Replace the illustrated portrait placeholders with image elements pointing to your photos (for example, `assets/liu.jpg`).
- Keep both `data-en` and `data-zh` values when changing bilingual copy.

## Publish

This repository includes a GitHub Actions workflow that deploys the site to GitHub Pages whenever changes are pushed to `main`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions** if GitHub does not set it automatically.
